# מאגר הפסיקה (/rulings)

מאגר פסיקה בר חיפוש, ולצידו מנוע שאילתות למאגרים הרשמיים. העמוד נמצא ב-`/rulings`,
והוא מוגש גם כמסמך סטטי מלא לזחלנים שאינם מריצים JavaScript.

## הכלל שהמאגר קיים כדי לאכוף

**שום רשומה אינה נכתבת מהזיכרון.** כל רשומה נשענת על מקור שכבר פורסם: מאמר של המשרד
(`article`), קישור ציבורי (`sources`), או שניהם. נושא שאין עליו רשומה מוצג כריק, ומקבל
שאילתה מוכנה למאגרים הרשמיים. מאגר פסיקה שממציא תשובה גרוע ממאגר שאומר שאין לו אחת.

## איפה הדברים יושבים

| קובץ | תפקיד |
| --- | --- |
| `src/data/rulings.json` | המקור היחיד לאמת. כל הרשומות. |
| `src/lib/rulings.ts` | הטיפוסים, התחומים, שאילתות המאגרים החיצוניים, והחיפוש. |
| `src/lib/hebrewSearch.ts` | נרמול עברי משותף (סופיות, גרשיים, ניקוד), משמש גם את חיפוש האתר. |
| `src/pages/Rulings.tsx` | העמוד. כל המצב יושב ב-URL, ולכן חיפוש הוא קישור. |
| `supabase/functions/lalum-assistant/rulings.data.ts` | קובץ נגזר. הפסיקה שהעוזר בצ׳אט רשאי לצטט. |

## הוספת פסק דין

1. הוסיפו רשומה ל-`src/data/rulings.json`. שדות חובה: `id`, `citation`, `court`, `date`
   (ISO, לצורך מיון), `dateLabel` (כפי שכותבים בעברית), `jurisdiction`, `areas`, `tags`,
   `holding`, `sources`. השדות `caption`, `bench`, `facts`, `issue`, `implications`,
   `quote` ו-`article` נוספים כשהמקור מחזיק אותם, ולא מולאו כדי למלא סעיף.
2. הריצו `node scripts/sync-assistant-rulings.mjs` כדי לעדכן את הקובץ הנגזר של העוזר.
   `--check` נכשל כשהקובץ אינו מסונכרן, ומתאים לשער בבנייה.
3. `npm run build` מריץ את `tsc` ואת `build-check`, ולכן רשומה חסרת שדה חובה נופלת בבנייה
   ולא בסקירה.

## התחומים

ארבעה תחומים מוגדרים ב-`AREAS` שב-`src/lib/rulings.ts`: נדל״ן ומקרקעין, התחדשות עירונית,
בינה מלאכותית ומשפט, ומקצוע עריכת הדין. כל תחום מחזיק ב-`terms` את המונחים שבהם הפסיקה
בו מאונדקסת במאגרים הרשמיים, והם משמשים גם כשאילתות מוכנות. תחום שאין בו רשומה מוצג
ככזה, ומקבל את השאילתות שלו: מי שהגיע לחפש דייר סרבן צריך לראות שהנושא קיים ולקבל
שאילתה שעובדת, ולא תיבת חיפוש שמחזירה כלום בשקט.

## תקן האימות

רשומה נכנסת רק כשהאזכור, הערכאה, התאריך והתוצאה עולים ממקור שאפשר לפתוח: פסק הדין עצמו,
מאגר פסיקה מלא, או שני מקורות עצמאיים שמוסרים אותו דבר. מקור יחיד שהוא דף שיווקי אינו
מספיק לאזכור שאין לו אישוש נוסף. המקור שממנו אומתה הרשומה נרשם ב-`sources`, כדי שהקורא
יוכל לבדוק אותה בעצמו ולא רק להאמין לתמצית. תמצית נכתבת ממה שהמקור אומר, וסעיף שהמקור
אינו מחזיק נשאר ריק.

## המאגרים החיצוניים

טופסי החיפוש של הרשות השופטת, נבו ופסקדין מקבלים טופס ולא שאילתה ב-URL, ולכן קישור
שמתיימר להעביר אליהם את מילות המבקר היה משמיט אותן בשקט. לכן שאילתה נשלחת כחיפוש ממוקד
אתר (`site:`), שמעביר את המילים ונוחת על מסמכים אמיתיים באותו מאגר, וטופס החיפוש של המאגר
מוצע לצידה.

## העוזר בצ׳אט

`supabase/functions/lalum-assistant/index.ts` מחזיק את הנחיות ההפעלה של הסוכן: מענה רק
מתוך החומר המאומת, ואמירה מפורשת כשאין תשובה במאגר, במקום לייצר אחת. הפסיקה שהוא רשאי
לצטט היא הקובץ הנגזר, כלומר אותו מאגר שהעמוד מציג. פריסה: `supabase functions deploy
lalum-assistant`.
